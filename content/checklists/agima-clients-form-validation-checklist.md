description: Чек-лист для валидации формы «Стать клиентом» и базового UX поведения полей и ошибок.
items:
  - страница открывается без явных визуальных поломок
  - блок Контактные данные отображается корректно
  - все поля и кнопка отправки видимы
  - обязательные поля визуально понятны
  - поле Email принимает корректный email
  - поле Email отклоняет значение без домена
  - поле Email отклоняет значение с пробелом
  - поле Email отклоняет кириллицу в email, если формат этого не допускает
  - поле Email отклоняет некорректную структуру после @
  - поле Email показывает понятную ошибку при невалидном значении
  - поле Телефон принимает корректный номер
  - поле Телефон не принимает слишком короткое значение
  - поле Телефон не принимает буквы
  - поле Телефон не принимает смешанные значения 123abc
  - поле Телефон не принимает чрезмерно длинную строку
  - поле Телефон корректно обрабатывает copy-paste
  - поле Телефон ограничивает ввод по формату или валидирует при отправке
  - кнопка submit не отправляет форму с невалидными данными
  - после исправления ошибок форма может быть отправлена
  - ошибки сбрасываются после ввода валидных значений
  - текст ошибок читаемый
  - ошибки показываются рядом с нужным полем
  - пользователь понимает, что именно нужно исправить
